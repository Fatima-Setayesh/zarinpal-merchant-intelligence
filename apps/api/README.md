# API Ownership Placeholder

This directory is reserved for the teammate-owned backend and data-serving API.

No backend implementation exists here yet. The teammate will define the backend architecture and is solely responsible for backend business logic, dataset engineering, preprocessing, analytical calculations, segmentation, statistics, storage strategy, numerical correctness, analytical tests, and performance.

This placeholder intentionally does not choose or scaffold a backend framework, runtime, ORM, database, analytical database, API style, or deployment architecture. Those decisions belong to the teammate.

Frontend integration needs are documented as proposals in:

- [Frontend–backend boundaries](../../docs/integration/frontend-backend-boundaries.md)
- [Draft contracts](../../docs/integration/draft-contracts.md)

All proposed contracts require teammate approval before implementation. This directory must not be populated with backend or analytical code by frontend-focused tasks unless ownership is explicitly expanded.
